منظومة توصيف المقررات والمواءمة الأكاديمية — نسخة HTML أولية
كلية علوم الرياضة – جامعة مدينة السادات

الملفات الأساسية:
- index.html: واجهة التطبيق العربية RTL.
- styles.css: التنسيق والتصميم المتجاوب.
- app.js: إدارة السجلات وتسجيل الدخول.
- cloud-config.js: إعداد الاتصال العام بـ Supabase.
- supabase_setup.sql: إنشاء الجداول وسياسات الأمان.
- README.md وDEPLOY_AR.md: وصف المشروع وخطوات الرفع والنشر.

الرفع إلى GitHub:
1. أنشئ مستودعًا جديدًا.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون index.html في الجذر مباشرة.
3. لتفعيل GitHub Pages: Settings > Pages ثم اختر الفرع main والمجلد /(root).
4. لقاعدة بيانات مشتركة، أنشئ مشروع Supabase ونفّذ ملف supabase_setup.sql ثم ضع Project URL والمفتاح العام anon/publishable فقط في cloud-config.js.

تحذير أمني: لا ترفع مفتاح service_role أو أي مفتاح سري أو كلمة مرور إلى GitHub.

الوضع التجريبي المحلي يحفظ البيانات في المتصفح الحالي فقط. هذه نسخة تأسيسية؛ لم تُستورد تلقائيًا كل البيانات الرسمية من ملفات الكلية، ولم يُنفذ بعد تصدير توصيف Word مطابق للقالب الرسمي أو محرك اقتراح نواتج التعلم. يجب استكمالها ومراجعتها قبل الاستخدام الرسمي.

=== تحديث: توصيف المقررات التفاعلي ===
- data.js: بيانات مستخرجة من ملفي «توصيف البرنامج 2026» و«نواتج التعلم المستهدفة»: 96 مقررًا (162 ساعة) و49 ناتج تعلم للبرنامج ومصفوفة A-D واستراتيجيات التعليم وأساليب التقييم ومؤشرات الأداء.
- spec.js: قائمة منسدلة للمقررات، توليد مسودة نواتج المقرر، تعديل مباشر، طباعة A4، تصدير JSON، وتبويب لنواتج البرنامج وتغطيتها.
- مصفوفة ملف التوصيف مكتملة لمجال المعرفة (A) فقط؛ المجالان المهني (C) والعام (D) فارغان، والذهني (B) شبه فارغ. الاقتراحات الآلية موسومة «مقترح للمراجعة» ولا تُعتمد قبل مراجعة لجنة البرنامج.
- لتجديد data.js عند تحديث التوصيف، أعد استخراج الجداول وفق نفس البنية.

=== تحديث 2: التحرير والرفع ===
- إضافة/تعديل/حذف نواتج تعلم البرنامج (تبويب نواتج البرنامج) وإضافة/تعديل/حذف نواتج المقرر (صفحة التوصيف). أزرار التحرير والرفع تظهر للمسؤول المسجل فقط.
- رفع ملفات Word (.docx) وExcel (.xlsx) للتعرف على النواتج: تظهر نتيجة التعرف (جديد / نص مختلف / مطابق) للمراجعة ولا يُطبّق شيء قبل التأكيد. الصيغ القديمة .doc و.xls غير مدعومة؛ احفظها بالصيغة الحديثة أولًا.
- النسخة الاحتياطية JSON تحفظ كل التعديلات ويمكن استرجاعها من نافذة الرفع.
- التعديلات تُخزَّن في المتصفح (localStorage). للمشاركة بين المستخدمين يلزم ربط Supabase وإضافة حفظ سحابي لها، وهذا لم يُنفَّذ بعد.
