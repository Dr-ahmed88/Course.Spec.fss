# منظومة توصيف المقررات والمواءمة الأكاديمية

نسخة HTML أولية باللغة العربية (RTL) لكلية علوم الرياضة – جامعة مدينة السادات.

## الملفات
- `index.html` — واجهة التطبيق.
- `styles.css` — التنسيق والتصميم.
- `app.js` — منطق التطبيق وإدارة السجلات.
- `cloud-config.js` — إعدادات Supabase العامة (اتركها فارغة حتى تجهز مشروعك).
- `supabase_setup.sql` — الجداول وسياسات الوصول.
- `DEPLOY_AR.md` — دليل الرفع إلى GitHub وNetlify وربط Supabase.

## تجربة محلية
نزّل الملفات وافتح `index.html` في متصفح حديث. الوضع المحلي للتجربة فقط، والبيانات تُحفظ في المتصفح نفسه.

## مهم قبل الاستخدام الرسمي
هذه نسخة تأسيسية وليست نظامًا مكتملًا للاعتماد. لم تُستورد تلقائيًا جميع بيانات المقررات ونواتج البرنامج من ملفات الكلية، ولم يُنفذ بعد إنشاء توصيف Word مطابق للقالب الرسمي أو محرك اقتراح نواتج التعلم. راجع البيانات علميًا قبل اعتمادها.

## الأمان
لا تضع كلمة مرور أو مفتاح `service_role` أو أي مفتاح سري داخل ملفات الواجهة الأمامية أو مستودع GitHub. المفتاح العام `anon/publishable` فقط هو المسموح باستخدامه في الواجهة، مع تفعيل سياسات RLS في Supabase.
